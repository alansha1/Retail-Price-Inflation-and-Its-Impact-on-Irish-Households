# Retail-Price-Inflation-and-Its-Impact-on-Irish-Households
Retail price inflation in Ireland from 2020 onward is analysed using CPI data to compare sectoral and urban–rural price trends, then forecast with ARIMA and machine‑learning models to assess impacts on low‑income households.
Ireland Retail Price Inflation Analysis
Analysed 10+ years of CSO CPI data to measure inflation's impact on Irish households.
Tools used: Python · pandas · SQL · ARIMA · LSTM · Random Forest · Tableau · Power BI
Key findings: Benchmarked 3 forecasting models to identify inflation trends across household categories.
